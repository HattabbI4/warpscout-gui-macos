# Contributing / Как участвовать

Build the app and run the [local tests](README_EN.md#build-and-test) before opening a pull request. Describe the change and the macOS version you tested. For UI changes, update both localizations and include a screenshot with example data. Happy to take bug reports with a short reproduction. Report vulnerabilities through [SECURITY.md](SECURITY.md).

Перед pull request соберите приложение и запустите [локальные тесты](README.md#сборка-и-тесты). Опишите изменение и укажите версию macOS, на которой его проверили. Для изменений интерфейса обновите обе локализации и приложите снимок с тестовыми данными. В баг-репорте укажите шаги воспроизведения. Для уязвимостей используйте [SECURITY.md](SECURITY.md).
