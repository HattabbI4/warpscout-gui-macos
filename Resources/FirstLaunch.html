Первый запуск на Mac

  1. Перетащите WarpScout.app в «Программы» (Applications). Затем откройте «Программы» в Finder и дважды нажмите WarpScout. Если появилось окно сканера, установка завершена.
  2. Если macOS сообщает, что не может проверить разработчика или приложение, нажмите «Готово» (или «ОК»). Эта сборка не прошла нотарификацию Apple. Продолжайте, только если вы доверяете источнику загрузки.
  3. Откройте  → Системные настройки → Конфиденциальность и безопасность. Если браузер запросит разрешение открыть «Системные настройки», подтвердите переход.
    Открыть раздел «Безопасность»
  4. Прокрутите до раздела «Безопасность». Рядом с сообщением о блокировке WarpScout нажмите «Всё равно открыть». В некоторых версиях macOS кнопка называется «Подтвердить вход». Подтвердите действие с помощью Touch ID или пароля, если потребуется, и нажмите «Открыть».

При первом запуске потребуется интернет: WarpScout скачает ядро сканера с GitHub. Если загрузка прервётся, откройте «Настройки» в приложении и нажмите «Загрузить ядро».

Кнопки рядом с WarpScout нет?

Повторите попытку открыть приложение из «Программ», закройте предупреждение и снова откройте раздел настроек. На рабочем Mac разрешение может контролировать администратор.

Если система сообщает о вредоносном ПО или повреждении приложения, остановите установку. Эта инструкция относится к предупреждению о непроверенном разработчике.

First launch on Mac

  1. Drag WarpScout.app into Applications. Open Applications in Finder and double-click WarpScout. If the scanner window opens, setup is complete.
  2. If macOS says it cannot verify the developer or check the app, click Done (or OK). This build has not been notarized by Apple. Continue only if you trust the download source.
  3. Go to  → System Settings → Privacy & Security. If your browser asks to open System Settings, confirm.
    Open Security settings
  4. Scroll to Security. Find the message naming WarpScout and click Open Anyway. Use Touch ID or enter your password if prompted, then click Open.

On first launch WarpScout needs an internet connection to download the scanner core from GitHub. If it fails, open Settings in the app and click Download core.

Can’t find Open Anyway?

Try opening WarpScout from Applications again, dismiss the alert, then return to Privacy & Security. On a managed Mac, your administrator may control this setting.

If macOS reports malware or a damaged app, stop installation. These steps apply to an unverified developer warning.
