# Security reports / Сообщения об уязвимостях

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/HattabbI4/warpscout-gui-macos/security/advisories/new). Include the app and core versions, macOS version and steps to reproduce with test data. Remove WARP account files, device keys, access tokens and exported profiles from attachments.

Сообщайте об уязвимостях через [закрытую форму GitHub](https://github.com/HattabbI4/warpscout-gui-macos/security/advisories/new). Укажите версии приложения, ядра и macOS, приложите шаги воспроизведения на тестовых данных. Удалите из вложений файлы аккаунта, ключи устройства, токены и экспортированные профили.
